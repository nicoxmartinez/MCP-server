## Servidor MCP
Permite conectar modelos de inteligencia artificial para gestionar archivos locales y fuentes de datos.

Instalar el SDK Oficial de MCP: 
```bash
pip install mcp
```

Instalar el modulo en el entorno virtual:
```bash
.venv/bin/python3 -m pip install "mcp[cli]"
```

Instalar panel web local: MCP Inspector:
```bash
npx @modelcontextprotocol/inspector .venv/bin/python3 main.py
```
